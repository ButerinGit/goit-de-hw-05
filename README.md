# GoIT Data Engineering — HW-05

## Kafka та Python: симуляція датчиків і система сповіщень

### Опис проєкту

Проєкт демонструє роботу Apache Kafka разом із Python для збору показників датчиків, їх обробки та формування попереджень.

### Використані технології

- Python 3
- Apache Kafka 3.9.1
- Docker та Docker Compose
- Бібліотека kafka-python

### Структура проєкту

- `docker-compose.yml` — запуск Kafka через Docker.
- `create_topics.py` — створення Kafka-топіків.
- `sensor.py` — генерація випадкових показників температури та вологості.
- `processor.py` — обробка показників і формування попереджень.
- `alerts.py` — отримання та відображення попереджень.
- `README.md` — опис проєкту.

### Kafka-топіки

1. `building_sensors_student` — отримання показників датчиків.
2. `temperature_alerts_student` — попередження про високу температуру.
3. `humidity_alerts_student` — попередження про критичну вологість.

### Логіка роботи

Датчик генерує випадкові значення:

- Температура: від 25 до 45 °C.
- Вологість: від 15 до 85%.

Обробник формує попередження за такими умовами:

- Температура понад 40 °C.
- Вологість понад 80% або нижче 20%.

Програма `alerts.py` отримує попередження з відповідних топіків і виводить їх на екран.

### Приклад роботи

Якщо температура датчика становить 42.71 °C, система формує повідомлення:

`Temperature is too high!`

### Запуск проєкту

1. Запустити Kafka: `docker compose up -d`.
2. Створити топіки: `py create_topics.py`.
3. Запустити споживач попереджень: `py alerts.py`.
4. Запустити обробник: `py processor.py`.
5. Запустити датчик: `py sensor.py`.

Програми `alerts.py`, `processor.py` та `sensor.py` запускаються в окремих терміналах.

### Висновок

У результаті виконання роботи реалізовано систему обміну повідомленнями через Apache Kafka, генерацію показників датчиків, перевірку критичних значень і надсилання автоматичних попереджень.
